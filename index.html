MergePriority
helper_classes.py ■ implement

A wrapper so Python's heapq (a min-heap) behaves like a max-heap for BPE. Used inside run_train_bpe to always pop the most frequent merge candidate.

What you fill in
class MergePriority:
    def __init__(self, freq, pair):
        self.freq = freq   # how many times this pair appears
        self.pair = pair   # (bytes_a, bytes_b)

    def __lt__(self, other):
        # heapq always pops the "smallest". We want HIGHEST freq first.
        # Tie-break: if freq is equal, return the LEXICOGRAPHICALLY GREATER pair.
        # Example: (b'A', b'C') beats (b'A', b'B') on a tie.
        raise NotImplementedError
How it connects
import heapq
heap = []
heapq.heappush(heap, MergePriority(freq=10, pair=(b't', b'h')))
heapq.heappush(heap, MergePriority(freq=25, pair=(b'e', b's')))
node = heapq.heappop(heap)   # should pop freq=25 first
print(node.freq, node.pair)  # 25, (b'e', b's')

run_train_bpe
adapters.py ■ implement

Train a byte-level BPE tokenizer from scratch on a text file.

Algorithm
1. Call helper_functions.pre_tokenizer_train(text, special_tokens)
   → get dict: {(b'l', b'o', b'w'): 5, ...}

2. Initialize vocab: ids 0–255 map to single bytes.
   Then add special tokens as single entries.

3. Build pair_counts (how often each adjacent pair appears across all
   pre-tokens, weighted by frequency) and pair_locs (which pre-tokens
   contain each pair).

4. Push all pairs onto a heap of MergePriority objects.

5. Loop until len(vocab) == vocab_size:
   a. Pop best pair from heap. Skip if its stored count is stale.
   b. Skip if either element is a special token.
   c. Merge: add new_token = A+B to vocab, record (A,B) in merges list.
   d. For every pre-token containing this pair:
      - Remove old pairs that overlap the merge site.
      - Add new pairs created by the merge.
      - Push updated MergePriority entries for changed pairs.
Helper functions you should use
# From helper_functions.py (already imported in adapters.py)
pretokens = helper_functions.pre_tokenizer_train(text, special_tokens)
# Returns: dict[tuple[bytes, ...], int]

# From helper_classes.py
heapq.heappush(heap, helper_classes.MergePriority(freq, pair))
⚠ Efficiency — do not skip

After each merge, only update pair counts for pairs overlapping the merge site. Do not re-scan the whole corpus. The speed test runs on a small corpus and fails if your implementation takes >1.5 seconds.

run_softmax
adapters.py ■ implement
Numerically stable formula
shifted  = x - x.max(dim, keepdim=True)   ← subtract max first
exp_x    = exp(shifted)
softmax  = exp_x / exp_x.sum(dim, keepdim=True)

Why subtract max? exp(1000) overflows to inf → NaN.
Subtracting max doesn't change the result (softmax is shift-invariant).

Efficient implementation pattern
# 1. Stack per-head weights into one big matrix
W_Q = torch.cat([weights[f'q_heads.{i}.weight'] for i in range(num_heads)], dim=0)
# W_Q shape: (num_heads * d_k, d_model)

# 2. One matmul for all heads at once

# 3. Reshape to separate heads

# Q shape: (B, num_heads, T, d_k)

# 4. Build causal mask and call your attention

# 5. Reassemble and project

AdamW optimizer
adapters.py → get_adamw_cls() ■ implement
Update rule (per-parameter, t starts at 1)
m  = β₁·m + (1−β₁)·g
v  = β₂·v + (1−β₂)·g²
αt = lr × √(1−β₂ᵗ) / (1−β₁ᵗ)       ← bias correction
θ -= αt × m / (√v + ε)               ← gradient update
θ -= lr × weight_decay × θ           ← weight decay (decoupled)
Skeleton (subclass torch.optim.Optimizer)
class AdamW(torch.optim.Optimizer):
    def __init__(self, params, lr, betas=(0.9, 0.999), eps=1e-8, weight_decay=0.0):
        super().__init__(params, dict(lr=lr, betas=betas, eps=eps, weight_decay=weight_decay))

    def step(self, closure=None):
        for group in self.param_groups:
            for p in group['params']:
                if p.grad is None: continue
                state = self.state[p]           # per-param dict (persists across steps)
                t = state.get('step', 0) + 1
                # ... update m, v, apply update rule ...
                state['step'] = t

def get_adamw_cls():
    return AdamW

run_get_lr_cosine_schedule
adapters.py ■ implement
Three phases
# Warmup (it < warmup_iters):
  lr = (it / warmup_iters) × max_lr

# Cosine decay (warmup_iters ≤ it ≤ cosine_cycle_iters):
  progress = (it − warmup_iters) / (cosine_cycle_iters − warmup_iters)
  lr = min_lr + 0.5 × (1 + cos(π × progress)) × (max_lr − min_lr)

# After cosine (it > cosine_cycle_iters):
  lr = min_lr

run_gradient_clipping
adapters.py ■ implement
Algorithm
# 1. Collect all params that HAVE a gradient (skip p.grad is None)
# 2. Compute global L2 norm across ALL gradients combined
total_norm = sqrt( sum( p.grad.norm()² for p with grad ) )

# 3. If total_norm > max_l2_norm, scale ALL gradients by the same factor
clip_coef = max_l2_norm / (total_norm + 1e-6)
if total_norm > max_l2_norm:
    p.grad *= clip_coef   # in-place for each p
